✨ COSA DOVREBBE SUCCEDERE:

✅ SUCCESSO (se tutto è configurato bene):

   → Seleziona: cleasil@gmail.com
   → Clicca: Accetta permessi
   → Torna nell'app
   → Vedi: "✅ Connesso come cleasil@gmail.com"

❌ ERRORE (se qualcosa non va):

   → Appare un errore nella pagina

🔍 SE NON FUNZIONA:

1. Premi F12 per aprire la Console
2. Clicca di nuovo il bottone "🔑 Accedi con Google"
3. Guarda la Console (tab "Console")
4. Cerca il messaggio di errore ROSSO

Inviami UNO di questi errori:
   ❌ "Redirect URI mismatch"
   ❌ "Invalid client"
   ❌ "Origin not authorized"
   ❌ "Consent screen not configured"
   ❌ Altro (scrivi qual è)

💡 SE VEDI QUESTO ERRORE:

"Redirect URI mismatch"
→ Ho bisogno di aggiungere http://localhost:3000/callback

"Origin not authorized"
→ Ho bisogno di aggiungere http://localhost:3000 (senza /callback)

"Invalid client"
→ C'è un problema con il Client ID

"Consent screen not configured"
→ C'è un problema col setup OAuth
