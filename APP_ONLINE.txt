🔧 ADESSO CONFIGURA GOOGLE (10 MINUTI):

1️⃣  APRI IMPOSTAZIONI (⚙️):
    - Click sulla tab "⚙️ Impostazioni" in basso

2️⃣  OTTIENI GOOGLE CLIENT ID:
    - Apri una nuova tab: https://console.cloud.google.com
    - Click "Crea progetto"
    - Nome: ScadenzeApp
    - Abilita API:
      * Google Calendar API
      * Gmail API
    - Credenziali → OAuth 2.0 → Applicazione Web
    - Aggiungi "Origini JavaScript autorizzate": http://localhost:3000
    - Copia il Client ID (termina con .apps.googleusercontent.com)

3️⃣  INCOLLA NEL'APP:
    - Torna a: http://localhost:3000/settings
    - Incolla il Client ID nel campo
    - Click "🔑 Accedi con Google"
    - Seleziona il tuo account Gmail
    - Click "Accetta permessi"

4️⃣  VERIFICA CONNESSIONE:
    - Vedi "✅ Connesso come tu@gmail.com"? ✅
